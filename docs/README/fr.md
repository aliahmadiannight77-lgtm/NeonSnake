# 🐍 NeonSnake

NeonSnake est un jeu Snake inspiré de l'esthétique cyberpunk, avec des effets néon. Il est développé avec JavaScript, HTML, CSS et Vite.

## ✨ Fonctionnalités

- Plusieurs skins de serpent
- Skins légendaires
- Système économique avec pièces et diamants
- Commandes au clavier et tactiles
- Effets sonores et visuels
- Prise en charge de neuf langues
- Gestion des mises en page RTL et LTR
- Sauvegarde locale de la progression et des paramètres
- Architecture JavaScript modulaire

## 🛠️ Prérequis

- Node.js 20.19+ ou 22.12+
- npm

## 🚀 Installation

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Développement

```bash
npm run dev
```

## 📦 Compilation de production

```bash
npm run build
```

## 👀 Prévisualisation

```bash
npm run preview
```

## 🌍 Langues prises en charge

Persan, anglais, allemand, arabe, français, espagnol, turc, russe et chinois.

## 💾 Stockage des données

La progression et les paramètres sont enregistrés localement dans le navigateur. La synchronisation cloud n'est pas encore implémentée. La suppression des données du navigateur peut entraîner la perte de la progression sauvegardée.
