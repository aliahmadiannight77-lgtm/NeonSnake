# 🐍 NeonSnake

NeonSnake ist ein Cyberpunk-inspiriertes Snake-Spiel mit Neon-Effekten. Es wurde mit JavaScript, HTML, CSS und Vite entwickelt.

## ✨ Funktionen

- Verschiedene Snake-Skins
- Legendäre Skins
- Wirtschaftssystem mit Münzen und Diamanten
- Tastatur- und Touch-Steuerung
- Sound- und visuelle Effekte
- Unterstützung für neun Sprachen
- RTL- und LTR-Layout
- Lokale Speicherung von Spielfortschritt und Einstellungen
- Modulare JavaScript-Architektur

## 🛠️ Voraussetzungen

- Node.js 20.19+ oder 22.12+
- npm

## 🚀 Installation

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Entwicklungsserver starten

```bash
npm run dev
```

## 📦 Produktionsversion erstellen

```bash
npm run build
```

## 👀 Vorschau starten

```bash
npm run preview
```

## 🌍 Unterstützte Sprachen

Persisch, Englisch, Deutsch, Arabisch, Französisch, Spanisch, Türkisch, Russisch und Chinesisch.

## 💾 Datenspeicherung

Spielfortschritt und Einstellungen werden lokal im Browser gespeichert. Eine Cloud-Synchronisierung ist derzeit nicht implementiert. Das Löschen des Browser-Speichers kann gespeicherte Daten entfernen.
