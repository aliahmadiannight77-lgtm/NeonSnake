# 🐍 NeonSnake

NeonSnake es un juego de Snake inspirado en la estética cyberpunk, con efectos de neón. Está desarrollado con JavaScript, HTML, CSS y Vite.

## ✨ Características

- Múltiples aspectos para la serpiente
- Aspectos legendarios
- Economía con monedas y diamantes
- Controles de teclado y pantalla táctil
- Efectos de sonido y visuales
- Compatibilidad con nueve idiomas
- Diseños RTL y LTR
- Guardado local del progreso y la configuración
- Arquitectura modular de JavaScript

## 🛠️ Requisitos

- Node.js 20.19+ o 22.12+
- npm

## 🚀 Instalación

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Desarrollo

```bash
npm run dev
```

## 📦 Compilación de producción

```bash
npm run build
```

## 👀 Vista previa

```bash
npm run preview
```

## 🌍 Idiomas disponibles

Persa, inglés, alemán, árabe, francés, español, turco, ruso y chino.

## 💾 Almacenamiento de datos

El progreso y la configuración se guardan localmente en el navegador. La sincronización en la nube todavía no está implementada. Borrar los datos del navegador puede eliminar el progreso guardado.
