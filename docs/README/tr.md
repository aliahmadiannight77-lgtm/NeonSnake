# 🐍 NeonSnake

NeonSnake, neon efektleri içeren siberpunk tarzından ilham alan bir yılan oyunudur. JavaScript, HTML, CSS ve Vite ile geliştirilmiştir.

## ✨ Özellikler

- Birden fazla yılan görünümü
- Efsanevi görünümler
- Altın ve elmas ekonomi sistemi
- Klavye ve dokunmatik kontroller
- Ses ve görsel efektler
- Dokuz dil desteği
- RTL ve LTR düzen desteği
- Oyun ilerlemesi ve ayarların yerel olarak kaydedilmesi
- Modüler JavaScript mimarisi

## 🛠️ Gereksinimler

- Node.js 20.19+ veya 22.12+
- npm

## 🚀 Kurulum

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Geliştirme

```bash
npm run dev
```

## 📦 Üretim Sürümü

```bash
npm run build
```

## 👀 Önizleme

```bash
npm run preview
```

## 🌍 Desteklenen Diller

Farsça, İngilizce, Almanca, Arapça, Fransızca, İspanyolca, Türkçe, Rusça ve Çince.

## 💾 Veri Depolama

Oyun ilerlemesi ve ayarlar tarayıcıda yerel olarak saklanır. Bulut senkronizasyonu henüz uygulanmamıştır. Tarayıcı verilerinin silinmesi kayıtlı ilerlemenin kaybolmasına neden olabilir.
