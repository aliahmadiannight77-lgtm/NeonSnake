# 🐍 NeonSnake

بازی مار با طراحی سایبرپانکی و جلوه‌های نئونی، توسعه‌یافته با JavaScript، HTML، CSS و Vite.

## ✨ امکانات

- پوسته‌های متنوع برای مار
- پوسته‌های افسانه‌ای
- سیستم اقتصادی سکه و الماس
- کنترل با صفحه‌کلید و نمایشگر لمسی
- افکت‌های صوتی و تصویری
- پشتیبانی از ۹ زبان
- پشتیبانی از چیدمان راست‌چین و چپ‌چین
- ذخیره محلی پیشرفت و تنظیمات
- معماری ماژولار JavaScript

## 🛠️ پیش‌نیازها

- Node.js نسخه 20.19 یا بالاتر، یا نسخه 22.12 به بالا
- npm

## 🚀 نصب

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ اجرای محیط توسعه

```bash
npm run dev
```

## 📦 ساخت نسخه نهایی

```bash
npm run build
```

## 👀 پیش‌نمایش نسخه نهایی

```bash
npm run preview
```

## 🌍 زبان‌های پشتیبانی‌شده

فارسی، انگلیسی، آلمانی، عربی، فرانسوی، اسپانیایی، ترکی، روسی و چینی.

## 💾 ذخیره‌سازی اطلاعات

پیشرفت بازی و تنظیمات در حافظه محلی مرورگر ذخیره می‌شوند. در حال حاضر همگام‌سازی ابری یا انتقال خودکار اطلاعات بین دستگاه‌ها پیاده‌سازی نشده است. پاک‌کردن داده‌های مرورگر ممکن است باعث حذف اطلاعات ذخیره‌شده شود.
