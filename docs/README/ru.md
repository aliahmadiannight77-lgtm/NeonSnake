# 🐍 NeonSnake

NeonSnake — игра «Змейка» в стиле киберпанк с неоновыми эффектами. Проект создан с использованием JavaScript, HTML, CSS и Vite.

## ✨ Возможности

- Различные облики змейки
- Легендарные облики
- Экономическая система с монетами и алмазами
- Управление клавиатурой и сенсорным экраном
- Звуковые и визуальные эффекты
- Поддержка девяти языков
- Поддержка RTL и LTR
- Локальное сохранение прогресса и настроек
- Модульная архитектура JavaScript

## 🛠️ Требования

- Node.js 20.19+ или 22.12+
- npm

## 🚀 Установка

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Запуск разработки

```bash
npm run dev
```

## 📦 Сборка проекта

```bash
npm run build
```

## 👀 Предварительный просмотр

```bash
npm run preview
```

## 🌍 Поддерживаемые языки

Персидский, английский, немецкий, арабский, французский, испанский, турецкий, русский и китайский.

## 💾 Хранение данных

Прогресс игры и настройки сохраняются локально в браузере. Облачная синхронизация пока не реализована. Очистка данных браузера может привести к потере сохранённого прогресса.
