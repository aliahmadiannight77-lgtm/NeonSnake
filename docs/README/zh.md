# 🐍 NeonSnake

NeonSnake 是一款采用赛博朋克风格和霓虹视觉效果的贪吃蛇游戏，使用 JavaScript、HTML、CSS 和 Vite 开发。

## ✨ 功能

- 多种蛇皮肤
- 传奇皮肤
- 金币与钻石经济系统
- 键盘和触屏控制
- 音效与视觉特效
- 支持九种界面语言
- 支持 RTL 和 LTR 布局
- 本地保存游戏进度和设置
- 模块化 JavaScript 架构

## 🛠️ 环境要求

- Node.js 20.19+ 或 22.12+
- npm

## 🚀 安装

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ 开发模式

```bash
npm run dev
```

## 📦 构建生产版本

```bash
npm run build
```

## 👀 预览

```bash
npm run preview
```

## 🌍 支持的语言

波斯语、英语、德语、阿拉伯语、法语、西班牙语、土耳其语、俄语和中文。

## 💾 数据存储

游戏进度和设置保存在浏览器本地。目前尚未实现云同步。清除浏览器数据可能会导致已保存的游戏进度丢失。
