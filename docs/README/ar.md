# 🐍 NeonSnake

NeonSnake هي لعبة ثعبان مستوحاة من أسلوب السايبربانك، وتتميز بتأثيرات النيون. تم تطويرها باستخدام JavaScript وHTML وCSS وVite.

## ✨ المميزات

- أشكال متعددة للثعبان
- أشكال أسطورية
- نظام اقتصادي يعتمد على العملات والألماس
- التحكم باستخدام لوحة المفاتيح والشاشة اللمسية
- مؤثرات صوتية وبصرية
- دعم تسع لغات
- دعم اتجاهي RTL وLTR
- حفظ تقدم اللعبة والإعدادات محلياً
- بنية JavaScript معيارية

## 🛠️ المتطلبات

- Node.js الإصدار 20.19 أو أحدث، أو 22.12 أو أحدث
- npm

## 🚀 التثبيت

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ تشغيل بيئة التطوير

```bash
npm run dev
```

## 📦 إنشاء نسخة الإنتاج

```bash
npm run build
```

## 👀 معاينة نسخة الإنتاج

```bash
npm run preview
```

## 🌍 اللغات المدعومة

الفارسية، الإنجليزية، الألمانية، العربية، الفرنسية، الإسبانية، التركية، الروسية والصينية.
