# 🐍 NeonSnake

A modular cyberpunk-style Snake game built with JavaScript, HTML, CSS and Vite.

## ✨ Features

- Multiple snake skins
- Legendary skins
- Coins and diamonds economy
- Keyboard and touch controls
- Sound and visual effects
- Nine interface languages
- RTL and LTR support
- Local progress persistence
- Modular JavaScript architecture

## 🛠️ Requirements

- Node.js 20.19+ or 22.12+
- npm

## 🚀 Installation

```bash
git clone https://github.com/aliahmadiannight77-lgtm/NeonSnake.git
cd NeonSnake
npm install
```

## ▶️ Development

```bash
npm run dev
```

## 📦 Production Build

```bash
npm run build
```

## 👀 Preview

```bash
npm run preview
```

## 🌐 Supported Languages

Persian, English, German, Arabic, French, Spanish, Turkish, Russian and Chinese.

## 💾 Data Storage

Game progress and settings are stored locally in the browser. Cloud synchronization is not currently implemented. Clearing browser storage may erase saved progress.
